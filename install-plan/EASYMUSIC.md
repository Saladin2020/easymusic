# Easy Music — studio usage guide

Seeded, seamlessly looping Thai game music: village, fields, market, shop, temple and shrine ambience, night,
river, Loy Krathong, Songkran, Hari Raya (kompang), battles and a title theme. Instruments are code synths of
ranat, khong wong, saw, khim, pi, khlui, ching/chap, klong thon, kompang and gong, plus chiptune voices. Agents
**pick presets, tweak params and seeds, render and export**. Every sample is synthesized from a seed; nothing is
generated by AI and nothing calls a network.

Install is local only. Do not push or modify the upstream GitHub repo.

## Paths

| What | Path |
|---|---|
| Install (package 0.1.0, `<SHA>` on master) | `/workspace/indie-studio/tools/easymusic` |
| CLI wrapper | `node /workspace/indie-studio/tools/easymusic-cli.mjs` |
| Studio projects | `/workspace/indie-studio/projects/<Name>/` |
| Song format | `/workspace/indie-studio/tools/easymusic/docs/FORMAT.md` |

The 15 presets are built in. A game's own songs (`songs/<id>.easymusic.json`), renders and engine exports belong
under `/workspace/indie-studio/projects/<Name>/`.

```bash
export EASYMUSIC_HOME=/workspace/indie-studio/tools/easymusic
export EASYMUSIC_WORKSPACE=/workspace/indie-studio/tools/easymusic
export EASYMUSIC_ALLOWED_DIRS=/workspace/indie-studio/projects
```

The wrapper sets these for you. Song ids must match `^[a-z0-9_-]+$`. For a game, pass
`--workspace /workspace/indie-studio/projects/<Name>` (init that folder once).

`export --out DIR` (single preset only) **writes into DIR without deleting it**. Use a fresh folder per export, or
the default `exports/easymusic-<preset>/`. `--preset all` cannot take `--out`.

## Commands

```bash
CLI="node /workspace/indie-studio/tools/easymusic-cli.mjs"
OUT=/workspace/indie-studio/projects/<Name>
$CLI init --workspace "$OUT"
$CLI list --workspace "$OUT" --tag raya
$CLI render raya_kompang --workspace "$OUT" --out "$OUT/music/raya.ogg"                  # loopable OGG
$CLI render raya_kompang --workspace "$OUT" --out "$OUT/preview.mp3" --loops 2 --fade 2   # listening copy
$CLI new kampung_day --from village_day --set mode=sol --set lead.instrument=flute --set seed=12 --workspace "$OUT"
$CLI check kampung_day --workspace "$OUT"
$CLI export kampung_day raya_kompang --preset godot --workspace "$OUT" --out "$OUT/exports/music-godot"
```

`--set`: `bpm=110`, `mode=la`, `tuning=thai7`, `seed=7`, `lead.instrument=pi`, `2.volume=0.6`, `*.octave=1`.

## MCP

`node /workspace/indie-studio/tools/easymusic/dist/mcp/server.js --workspace <dir>` (stdio) or add
`--http --port 8859`. Tools: `workspace_info`, `list_songs`, `get_song`, `write_song` (`dryRun`), `render_song`,
`export_music`. Ports: editor 8858, MCP HTTP 8859, Vite 5181.

## Engines

- **Godot 4.3+**: the `godot` export is a project with `easymusic/music/*.ogg` (loop + `loop_offset`),
  `easymusic/music.json` and the `MusicPlayer` autoload (`MusicPlayer.play(id, fade)`, `stop(fade)`,
  `position()`, `song_changed` signal). To add it to an existing game, copy the `easymusic/` folder and register
  `res://easymusic/music_player.gd` as an autoload named `MusicPlayer`.
- **PixiJS / web**: `easymusic-web.js` → `const m = await loadMusic("easymusic.json"); await m.play("village_day")`
  after a user gesture. It honours `loopStart` (intros). `@pixi/sound` loops whole files only.

## Content rules

- Instrumental only. Never ask for or describe the adhan, Quran recitation, religious chanting or vocals; the
  validator rejects those names and there is no voice synth.
- Keep the village multicultural: Raya kompang beside Loy Krathong, Songkran and the shrine street.
- `temple_calm` is ambience for the temple grounds, not ritual music.
