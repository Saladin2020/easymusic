# Easy Suite brand assets

Generated by the Easy Suite brand script (pixel logos, banners, social previews). Same frame, palette and
fonts across all ten tools; only the icon and accent colour change. Easy Music uses bamboo lime `#9bd13b`
and an icon of a music note over a ranat (Thai xylophone) keyboard; its banner and social art are a real
Easy Music editor view (waveform and piano roll of `raya_kompang`).

| File | Use |
|---|---|
| `banner-music.png` (1280×320) | README header |
| `social-music.png` (1280×640) | GitHub social preview: Settings → General → Social preview → Upload |
| `logo-music.png` (240×240), `logo-*-96.png` | Tool logos; the `-96` set is used by the suite table |

Fonts in the art: Press Start 2P and Kanit (both SIL OFL 1.1). v2 style: subtle green accent and a light
8-point star (girih) pattern on the teak, cream and gold palette.
